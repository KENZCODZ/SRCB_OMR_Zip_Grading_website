# SRCB OMR Grading System — Frontend

This is the React + TypeScript frontend for the **SRCB OMR & Zip-Grading System**, built with Vite and Vanilla CSS.

## 🚀 Quickstart

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

> Note: All `/api` fetch requests are automatically proxied to the Python FastAPI backend running at `http://127.0.0.1:8000` via [vite.config.ts](file:///c:/Users/SRCB-IT-ADMIN/SRCB_OMR_Zip_Grading_website/Frontend/vite.config.ts).

## 🧰 Build for Production

```bash
npm run build
```

For full documentation and system architecture, see the root [README.md](file:///c:/Users/SRCB-IT-ADMIN/SRCB_OMR_Zip_Grading_website/README.md).
